# 生日快乐 · 交互式祝福网站

一份送给「小卢同学」的生日惊喜网页（2026 年 11 月 21 日）。纯前端实现，无需服务器、无需安装任何依赖，双击就能打开。

## 文件结构

```
D:\shengrizhufu\
├── index.html   页面骨架（开场页 + 七个章节）
├── style.css    全部样式（礼物盒、蛋糕、卡片均为纯 CSS 绘制）
├── script.js    交互逻辑 + 集中配置区 CONFIG / V2
├── music.mp3    背景音乐（缺失时自动改用 Web Audio 合成的八音盒旋律）
├── surprise.jpg 隔空同享板块底部的实物礼物照片（滚动到此处淡入，懒加载 + 失败兜底）
├── cake_hers.jpg 「隔空同享」板块：你的蛋糕
├── cake_mine.jpg 「隔空同享」板块：我的蛋糕
├── test-regression.js  零依赖回归测试（Node 跑，不影响网页）
├── verify-edge.js  用系统 Edge 做真实渲染验证（可选，需 playwright-core）
├── verify-mobile.js  用系统 Edge 做手机端专项验证：溢出、懒加载兜底、飘字、终极彩蛋
├── verify-letter.js  用系统 Edge 验证「一封小信」信笺：排版、字体、拆信动画
└── README.md    本说明文档
```

三张图片都用 `<img>` 直接引入，与 `index.html` 同级，**不用打包、不用上传**；想换成自己的照片，直接同名替换即可（建议宽度 800px 左右、单张 300KB 以内）。

## 怎么打开

- **电脑**：双击 `index.html`，用浏览器（Edge / Chrome）打开即可。
- **手机**：把整个文件夹发到手机（或局域网共享），用手机浏览器打开 `index.html`。已适配刘海屏与触摸滑动。

## 网站流程与彩蛋

1. **开场礼物盒** —— 点击拆礼物，摇一摇有惊喜；**长按「长按 2 秒跳过开场」**可直接进入正文；首次打开会有「点这里拆礼物 ✦」引导气泡。
2. **主祝福页** —— 打字机逐字显示祝福语，可点「显示全文」或**直接点击祝福文字**跳过；下方是**情绪化倒计时**（越近越激动，剩 0 天当天自动放一次庆祝烟花）；打字结束后会出现**折叠卡**（生日 / 星座 / 今日标签）与**随机气泡**；点「收下这句祝福」或**长按祝福文字 1.2 秒**可盖上专属印章。
3. **许愿蛋糕** —— 三根蜡烛逐一点击吹灭（可再点亮）；**点「重新点燃蜡烛」后**才会出现愿望输入框，可写下一个只有自己能看到的小愿望（存本机）；蜡烛区会循环播放祝福语。
4. **时光手账** —— 5 张回忆卡片，左右滑动翻页；每张卡片右上角有 🎁 贴纸，**点击可翻面**看背面彩蛋；每张卡片可**放入自己的照片**（自动压缩，只存这台设备）。
5. **摘心愿星** —— 点亮散布的 5 颗星星，每颗一句话，集齐有花束彩蛋。
6. **生日回顾·隔空同享** —— 摆出两个人的蛋糕照片：`cake_hers.jpg`（你的蛋糕）与 `cake_mine.jpg`（我的蛋糕）做成**拍立得**并排展示（白色边框 + 轻阴影，中间留缝，手机窄屏自动变成上下排列）；滚动到这一节时**缓缓淡入**；**点击任意一张蛋糕**，图片会轻微放大并在点击位置飘出 🍰 / 🍴 的 emoji（该彩蛋遵循 `CONFIG.enableEasterEggs` 总开关，开启「减少动效」时改为只出文字提示），**第一次点击**时屏幕中央还会缓缓飘出一行「把我的心意，隔空传递给你 ✦」；**两张蛋糕下方**是实物礼物照片 `surprise.jpg` 和一句「看，这是我为你摆的生日快乐，嘻嘻 ✦」（图片最大宽度 80%、手机端 90%，带圆角与柔光阴影），**滚动到板块底部、或看到蛋糕照片时**才缓缓淡入出现。大图走 `loading="lazy"` 懒加载：滑到才加载，加载中显示淡粉灰占位 + 小转圈，**加载失败**则显示「图片走丢啦，但我的心意没有丢哦 ✦」。
7. **留言板** —— 写给寿星的话，保存在本机 localStorage，刷新不丢；可切换**弹幕视图**（列表 / 弹幕 / 暂停 / 慢中快 / 点击查看全文 / 长按 600ms 置顶）。弹幕**同屏最多 26 条**（`CONFIG.danmaku.maxOnScreen`），点「暂停」会冻结所有弹幕的动画。
8. **结尾页** —— 再放一次烟花、复制祝福链接、**回到开头 ↑**；**长按「生日快乐」标题 2 秒**有隐藏彩蛋；可生成生日海报（旧版打印版 + 新版**可编辑 Canvas 海报**）、复制分享文案；页尾有一行彩蛋提示。**终极彩蛋**：在结尾页**停留 30 秒**后，「回到开头 ↑」旁边会悄悄浮现一个半透明的小按钮「💌 还有一封小信」，点开是一张**信纸弹窗**，正文就是 `CONFIG.ending.secretLetter` 里你写的那封长信。

全局 UI：顶部有**滚动进度条**，右侧有**章节导航点**（7 个章节可跳转，滚动时高亮，窄屏自动隐藏）；右上角 ♪ 按钮可随时开关背景音乐；**左下角**有「减少动效」开关。（位置以 `style.css` 为准：`.music-btn` 用 `right/top`，`.reduce-fx` 用 `left/bottom`。）

### 新增彩蛋（v3）

| 触发方式 | 效果 |
|---|---|
| 依次按 `↑ ↑ ↓ ↓ ← → ← → B A` | 开发者祝福 + 全屏烟花 |
| 双击蛋糕 | 撒一把糖果色碎片 |
| 手机摇一摇（iOS 13+ 会先弹授权） | 顶部落彩带 |
| 点「隔空同享」里的蛋糕照片 | 图片轻微放大 + 飘出 🍰 / 🍴 |
| 第一次点蛋糕照片 | 屏幕中央缓缓飘出「把我的心意，隔空传递给你 ✦」 |
| 结尾页停留 30 秒 | 「回到开头 ↑」旁浮现「💌 还有一封小信」，点开是一封长信 |

彩蛋规则：同一时间只触发一个，触发后 3 秒内冷却；开启「减少动效」时只出文字、不播粒子。

### 进度存档

拆过礼物后，网站会在本机记下你的进度（吹过哪些蜡烛、点过哪些星星、是否写过愿望、是否发过留言、写到第几章）。**距上次访问超过 5 分钟**（阈值写在 `CONFIG.progressTexts.welcomeAfterMs`，单位毫秒）**且上次看的章节与当前章节不同**时，开场会提示「**欢迎回来，你上次看到第 N 章**」，点「继续」直接跳到上次那章；已完成的蜡烛与星星会自动显示为已完成状态。结尾页有「**重新开始**」，只清除浏览进度，愿望、留言、照片都会保留。

## 想改文案 / 名字 / 日期？

## 数据存储（全部在 localStorage，只存在这台设备上）

| key | 内容 | 说明 |
|---|---|---|
| `birthday_photos_v1` | `{ "0": base64, …, "poster": base64 }` | 卡片照片（key 为卡片序号）与海报专用照片；自动压到最长边 800px / JPEG 0.8 |
| `birthday_progress_v1` | `{ giftOpened, candlesBlown[], starsLit[], wishSaved, messagePosted, lastChapter, updatedAt }` | 浏览进度，「重新开始」只删这一个 |
| `birthday_pinned_v1` | `[t, …]` | 弹幕墙里被置顶的留言 |
| `birthday_danmaku_v1` | `{ view, speed }` | 弹幕/列表视图与速度偏好 |
| `birthday_poster_v1` | `{ tpl, text, photo }` | 海报模板、祝福语、所用照片 |
| `birthday_celebrated_v1` | `2026-11-21` | 生日当天的庆祝标记（每天只放一次） |
| `birthday_wish_v1` | 字符串 | 许愿卡片的愿望 |
| `birthday_guestbook_v1` / `birthday_guestbook_version` | 留言数组 / 版本号 | 留言板数据。**⚠️ 版本号（`birthday_guestbook_version`）与数据结构不匹配时，已有的旧留言不会被清空**：系统会先尝试迁移到新结构；迁移失败时把原文原样备份到 `birthday_guestbook_backup_v1`，并在留言列表末尾追加默认示例。只有在完全读不到任何原始数据时，才会写入一份默认示例。 |
| `birthday_guestbook_backup_v1` | 原始留言 JSON 字符串 | **仅在留言数据迁移失败时生成**的原文备份，用于人工找回；正常情况下不存在 |
| `birthday_reduce_fx` | `0` / `1` | 减少动效开关 |
| `birthday_v2_guided_v1` | `0` / `1` | 是否看过开场引导 |

存储说明：所有 key 都通过统一的 `Store` 封装读写（`script.js` 里搜索 `const Store =`），浏览器隐私模式下会自动降级为「内存存储」，本次浏览仍可用，关掉页面即失效；所有读写都带 try/catch。留言板与许愿愿望另有一层 try/catch 兜底。

照片写入策略：更换照片时**先删除旧的 `birthday_photos_v1` 再写新值**，避免新旧照片并存占满配额；写入前会统计 `localStorage` 当前总占用（预算 4.2MB），超限时提示「照片太大，已跳过」，不会写坏已有数据。

## 技术说明

- 零依赖、零构建：HTML + CSS + 原生 JavaScript。
- 动效：Canvas 粒子（星星 / 花瓣 / 烟花）、CSS 动画、滚动驱动。
- 音效：Web Audio 合成 chime / whoosh / ping / boom 四种音效。
- 数据：愿望与留言存 localStorage，仅保存在打开网页的这台设备上。
- 兼容：现代浏览器（Edge / Chrome / Safari / 微信内置浏览器）；尊重系统「减弱动态效果」偏好。
- 「减少动效」开启后：弹幕自动退回列表视图、彩蛋与当天庆祝只出文字、礼物 / 蛋糕 / 手账 / 愿望卡 / 印章 / 折叠卡动画停用，实物礼物图与拍立得不做淡入 / 放大 / 飘字。
- 海报：纯 Canvas 手绘（540×720，3 套模板、圆角照片裁切、正文折行、印章），未使用二维码库（右下角以文字形式写网址），下载为 PNG。
- 移动端手感：`html` / `body` 都加了 `overscroll-behavior-y: none`，滑到顶部或底部**不再触发整页橡皮筋回弹**，更像原生 App；左右滑动回忆手账时手势被关在 `.deck` 容器内（`overscroll-behavior-x: contain`），**不会带动整页左右晃动**；拍立得、按钮区、图片都设了 `max-width:100%`，窄屏无横向溢出。
- 大图兜底：`surprise.jpg` 走 `loading="lazy"` 懒加载 + `decoding="async"`；加载中显示淡粉灰占位与小转圈，加载失败显示「图片走丢啦，但我的心意没有丢哦 ✦」，不会出现长时间空白。
- 信纸质感：弹窗是一张**微黄信笺**（`#fdfbf7` + 淡金色横线纹理），正文用**楷体 18px / 行距 1.8**、首行缩进两字，抬头居中、落款与日期右下角右对齐；打开时**信封盖翻起 + 纸张从中间展开**（`clip-path` 动画）。

## 手动验收清单

1. **照片**：手账里点「放入照片」→ 选一张图 → 卡片显示照片、可更换/移除；刷新后仍在。
2. **进度**：吹蜡烛 + 点星星 + 写留言 → 刷新 → 开场出现「欢迎回来」；点「继续」跳回上次章节；结尾「重新开始」后进度清零但留言还在。
3. **弹幕**：留言板切「弹幕」→ 弹幕飘过；点一下暂停并显示全文；长按 600ms 出现「置顶」，置顶后该条在列表里排最前。
4. **倒计时**：把 `CONFIG.birthdayDay` 改成今天 → 页面显示「就是今天」并放一次庆祝；再刷新不会重复放。**测完记得改回 `birthdayMonth: 11`、`birthdayDay: 21`。**
5. **海报**：结尾页点「✎ 自定义海报」→ 换模板、改祝福语、选照片 → 「下载海报」得到 PNG；刷新后模板与文案仍在。
6. **彩蛋**：连按 `↑↑↓↓←→←→BA`、双击蛋糕、手机摇一摇各触发一次，且 3 秒内不重复触发。
7. **开场面**：长按「长按 2 秒跳过开场」→ 确认后直接进入正文；首次打开能看到引导气泡。
8. **折叠卡与印章**：打字结束后出现折叠卡，点击可展开；点「收下这句祝福」盖上印章，长按祝福文字也能盖。
9. **留言数据升级**：把 `DATA_VERSION` 改成 `'v3'` → 刷新 → 旧留言仍在、默认示例被追加到末尾；再把 `birthday_guestbook_v1` 改成乱码 → 刷新 → 列表只剩默认示例，原文进了 `birthday_guestbook_backup_v1`。
10. **实物礼物图**：滚到「生日回顾·隔空同享」板块**底部**（两张蛋糕拍立得下方）→ `surprise.jpg` 与那句 surpriseText 缓缓淡入；主祝福页不再出现这张图；刷新后默认仍是隐藏的。
11. **隔空同享**：滚到「生日回顾·隔空同享」→ 两张拍立得淡入；窄屏（≤600px）改为上下排列；点任意一张蛋糕 → 图片轻放大并飘出 🍰 / 🍴，**第一次点击**还会飘出中央那句「把我的心意，隔空传递给你 ✦」；开启「减少动效」后点击只出文字提示。
